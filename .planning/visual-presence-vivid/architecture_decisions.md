# Architecture decisions

1. Preserve the existing controller port and runtime hook. Add body channels inside the visual driver.
2. Keep raw native expressions pure. Add embodied preview buttons that request catalog behaviors.
3. Use normalized humanoid bones and bounded additive quaternions. Never modify VRM assets or spring bones.
4. Use procedural gesture tracks first. Add VRMA assets only with proven quality and licensing.
5. Generic defaults depend on rig capabilities. No production filename checks.
6. Honor the user's detailed design and implementation authorization without an additional design approval round.
7. Define procedural offsets in canonical VRM1 coordinates. Convert quaternion X/Z for VRM0, matching the installed VRMA retargeter.
8. Keep diagnostic timeline holds inside the isolated gallery. They sample the same driver after real base-animation ticks.
9. Validate neutral restoration with exact sampled quaternion components. Normalize scratch copies only for angle measurements; float32 authored clips need not have exactly unit-length quaternions.
