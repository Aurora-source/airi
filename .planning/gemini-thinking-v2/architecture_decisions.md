# Architecture decisions

## Isolation
Use the exact prior benchmark commit in the requested new worktree. Preserve original evidence and production branches.

## Reuse
Reuse the existing ledger, Gateway, corpus, timing collector, and reporting infrastructure.
Change benchmark code only when capability coverage or measurement correctness requires it.

## Authority
R7 selects attention. R2B authorizes inference. External WATCH and NOW observations cannot select models or thinking levels.
Provide an inactive configuration proposal. Do not implement production switching.

## Evidence
Use matched synthetic fixtures and separate blinded review material from the model key.
Keep subjective recommendations provisional. Do not claim measured first audio from text timings.

## Reservation review
Retain the full advertised input window as the strict financial bound.
Native countTokens accepts a different wire format and documents an example with a one-token generation difference.
Google does not document a guaranteed byte multiplier for tokenization.
Gateway injection, recaps, tools, schemas, and thought signatures can increase billable input after request construction.
Do not lower reservations with an unsupported estimate. The revised $5 ceiling safely admits all requested models.
The explicit output cap remains request-specific. It includes thinking and visible generation according to official documentation.

## Budget update
V2 now has a $5 total ceiling. The original $4.50 default remains for unrelated original-harness invocations.
An explicit increase records authorization without deleting settlements, reservations, or halted state.
V2 dispatch is sequential. The research runner has a separate $2 review threshold to avoid unnecessary spending.

## Live addendum
Evaluate 3.8 Live and Extended Thinking through their native Live API, separately from Flash text results.
Live allocation cannot exceed $1 of the remaining V2 allowance. The total stays $5.
If session costs or terminal usage cannot be bounded reliably, use documentation and authenticated metadata only.
Do not treat Extended Thinking turnComplete as background-work completion. Verify interaction_status semantics.
Live generated audio cannot silently replace Mura's local TTS voice. Any proposed alternative stays opt-in.

## Live admission decision
Do not dispatch paid Live sessions in this campaign.
Periodic usageMetadata does not establish terminal cumulative billing on interruption, failure, or close.
Extended Thinking can continue background work after an utterance ends. IDLE does not certify final billing.
The text-only parser and ledger cannot enforce the separate Live suballocation without new verified protocol support.
Use official documentation and authenticated metadata. Record zero Live spending and leave physical voice acceptance pending.
